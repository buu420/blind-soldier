# Blind Soldier 0.9.7

Echo-S 7 navigation now reads the scripts currently loaded by the game. The
reviewed compatibility data covers all 702 fields in each of Echo-S 1.24's five
field variants, including changed doors, native availability conditions,
shopkeepers and party members. Cross-room routes use the matching field layout.
Official stock language archives retain navigation support. Unknown overrides
do not receive guessed labels or English cutscene offsets.

The bike section retries an automatic-steering announcement when the speech
backend initially declines it. Steam automatic steering also keeps its native
input active while the same direction remains needed, and releases it when
driving becomes unavailable or the game loses focus.

New room descriptions cover the previously missing scenery throughout the game,
using the existing approved voice. Descriptions remain available from the normal
room readout and share the existing save-specific description history. Reviewed
doors and later story actions receive descriptions at their actual native events.
Blank or ambiguous art is not assigned invented scenery or character movements.

The final films now receive their timed descriptions outside the FIELD module,
including the post-credits scene. Credits are described when their native renderer
draws them; visible credit names are read without retaining an offscreen backlog.
Independent narration stops on suspension, focus loss, unreadable state or scene
replacement. Failed recordings retain spoken fallback while their cue is current.

Both the 2013/7th Heaven and Steam 2026 runtimes are included. Existing controls,
game dialogue and soundtrack are preserved. The existing audio-description
volume setting applies to the new recordings too.

Native-data regressions, recording checks and package validation are documented
in [validation](../validation/echo-narration-20261012.md). These checks establish
the reviewed native mappings and payloads; they do not substitute for live
endgame play, controller response or screen-reader listening.

Close the game before updating. Existing saves, settings, description history
and previously shipped recordings are preserved.
