# Blind Soldier 0.1.0-pre.7

This prerelease adds a compact, direct-extract installation option based on
the native installer and launcher supplied for this work.

- The native installer's original workflow is preserved: extract the archive
  into the Final Fantasy VII folder, run `Blind-Soldier-Installer.exe`, accept
  the administrator prompt, and choose **Yes** in the standard Windows dialog.
- Ordinary Steam and game launches then load Blind Soldier automatically.
- Legacy x86 `ff7_en.exe`, native x64 `FFVII.exe`, and installations containing
  both are supported. The installer registers only the versions it finds and
  never requires both.
- Separate architecture-matched launchers inject Reloaded-II before resuming
  the game. Shared Hooks loads before Blind Soldier.
- The ZIP includes the accessible Final Fantasy VII launcher, both Blind
  Soldier backends, Prism, audio description, footsteps, navigation data, and
  all other mod assets.
- Reloaded's manager, UI, updater, package tools, ASI loaders, and build debris
  are omitted. Only the dependency-closed loader files used by the native
  launcher are included.
- Run `Blind-Soldier-Installer.exe /uninstall` to remove the automatic launch
  registration. Extracted files are intentionally left in place.
- Existing third-party IFEO debugger registrations are never overwritten or
  removed. Reloaded's per-user pointer is swapped atomically, serialized across
  game instances, and restored after the game exits.

The portable installer preserves the supplied register-only behavior and does
not install Microsoft runtimes. It checks for Microsoft .NET Desktop Runtime
9.0.8 or a newer 9.0 patch for each detected game architecture before changing
the registry. The standard screen-reader-accessible setup from v0.1.0-pre.6
remains available and installs missing runtimes automatically.

Download `Blind-Soldier-Portable.zip`, verify it with the accompanying SHA-256
file if desired, and read `README-PORTABLE.txt` inside before installing.
