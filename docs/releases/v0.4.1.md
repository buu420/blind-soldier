# Blind Soldier 0.4.1 (Beta)

This beta makes the mod usable with screen readers other than NVDA. If you use
JAWS, or anything else, 0.4.0 and every release before it gave you no speech at
all; this one should simply work.

## What changed

### Speech

- Speaks through whichever screen reader you actually run, not only NVDA. The
  copy of the Prism speech library shipped for the 2013 runtime crashed when it
  examined three of the readers it supports - ZDSR, PCTalker and BoyPCReader.
  Those three are checked after NVDA and before JAWS, so with NVDA running
  nothing was ever wrong, and without it the crash happened before JAWS was ever
  reached.
  Blind Soldier caught the crash and fell silent. Prism is updated to 0.18.0,
  which examines those three without faulting.
- Follows the screen reader you are using while you play. The reader was chosen
  once when the game started and kept for the rest of the session, so starting
  the game before your screen reader, or switching readers partway through, meant
  silence until you restarted. Blind Soldier now notices and moves with you.
- Names the Prism version and the runtime architecture in the log, and lists the
  readers it found when it cannot use any of them. Silence is the hardest fault
  to report, and the previous message said only that nothing was found.

### Under the hood

- Covers the accented half of the field text table in the test suite. Accents and
  `ñ` were repaired in 0.2.1-beta.1, but every decoder test used plain ASCII, so
  the half of the table that only Spanish, French and German players ever reach
  had no test behind it.

## Testing requested

**If you use JAWS, this release is for you** - it is the first one that should
speak at all, and nobody has yet been able to confirm it does. The same applies
to ZoomText, SystemAccess, or any reader that is not NVDA.

- Start the game with your screen reader already running and confirm Blind
  Soldier speaks.
- Start the game *first*, then start your screen reader, and confirm speech
  begins without restarting the game.
- If you have two readers available, switch between them while the game runs.
- If anything is silent, the log now says which readers were found and which
  Prism it is using. `ff7_accessibility_reloaded.log` in the Blind Soldier folder
  is worth attaching to a report.

NVDA users: nothing about your setup changed deliberately, but the speech library
underneath did, so ordinary confirmation that everything still speaks is useful.

Steam 2026 x64 still needs play testing generally, as it did in 0.4.0.

## Installation

Two ZIPs are available:

- `Blind-Soldier-Portable.zip` is the complete dual-runtime package for Steam
  2026 x64 or installations that need both x86 and x64 support.
- `Blind-Soldier-2013-x86-Portable.zip` is the smaller package for direct 2013
  x86 or stock 7th Heaven/FFNx.

Close Final Fantasy VII and 7th Heaven, then extract the appropriate ZIP over
the existing Blind Soldier installation. Accessibility Mod Manager users can
install the matching prerelease-channel update directly.
