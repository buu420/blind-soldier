# Blind Soldier 0.9.1

This beta improves ordinary navigation inside the Highwind on legacy x86/7th
Heaven and Steam 2026 x64. Close the game before updating.

- Exits names the bridge, corridor, operations room, outside deck and Chocobo
  hold, including the return doors. They remain available between Story events.
- NPCs identifies the pilot, operations crew member and Chocobo handler.
  Navigate to the operations crew member and press normal Confirm to use the
  game's party formation, save and rest choices. Talk to the pilot to fly.
- The corridor's forward door resolves to the bridge variant the native game
  currently uses. Northern Crater access still waits for the game's own flag.
- Story guidance remains available during active events. Existing boarding,
  landing and interaction controls continue to apply.

Settings, saves, audio descriptions and description history are preserved.
Automated checks exercise both runtimes against their installed field archives,
including room routes from native arrival positions. Live gameplay,
hardware-controller delivery and listening tests remain unverified for this
repair. See [native validation evidence](../validation/highwind-interior-20261010.md).
