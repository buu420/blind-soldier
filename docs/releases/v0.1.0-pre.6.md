# Blind Soldier 0.1.0-pre.6

This prerelease fixes the setup startup crash and removes former-product
migration from the normal installer path.

- Setup now reads its engine version from the executable's published assembly
  metadata instead of a separate hard-coded value.
- This prevents the setup from downloading itself and then rejecting that same
  executable as too old.
- Setup uses only the current `%LOCALAPPDATA%\Blind Soldier` state, log, program,
  Start menu, and Windows registration paths.
- Files and registration under the former product name are not searched,
  imported, removed, or otherwise acted upon.

Download `Blind-Soldier-Setup.exe` for the standard screen-reader-accessible
installation. The installer is not code-signed yet, so Windows SmartScreen may
identify the publisher as unknown.
