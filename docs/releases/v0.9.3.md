# Blind Soldier 0.9.3

This beta repairs Sector 7 navigation on legacy x86/7th Heaven with Echo-S 7
and preserves the shared Steam 2026 x64 behavior. Close the game before updating.

- Exits offers "Enter Seventh Heaven" outside the bar whenever its native
  entrance is enabled, including returning after a previous visit.
- Exits names the pinball lifts between Seventh Heaven and the AVALANCHE
  hideout. Availability follows the native opening and busy state; automatic
  walking reaches the game's required interaction distance.
- NPCs offers "Item and Materia shopkeeper" at the shop's combined counter.
  Both purchases use this one native shop service. Navigate to the counter and
  use the game's normal Confirm button.
- Current Echo-S character and object identities are used for NPCs, Objects
  and Story. This also prevents stock object IDs from hiding visible characters.

Use the existing navigation controls and normal interaction buttons for doors,
lifts and conversations. Settings, saves, audio descriptions and description
history are preserved.

Automated checks use the installed stock fields and all five current Echo-S
1.24 variants: base, Aavock, ESUI, FT and Retouch. They cover re-entry, native
counter and lift approaches, late bar states, current NPC/object/Story identities,
disabled targets and changing or unloaded scripts in both test hosts.
Live gameplay, hardware-controller delivery and speech listening remain
unverified for this repair. See the
[native validation evidence](../validation/sector7-navigation-20261011.md).
