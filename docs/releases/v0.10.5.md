# Blind Soldier 0.10.5

This testing release repairs missing and incorrectly named NPC navigation targets. Close the game before updating.

- NPC discovery now handles the engine's normal model-lighting cache writes inside loaded scripts. These writes previously made reviewed fields appear unrecognized, removing their NPCs and other navigation targets.
- Character names follow the actor's native identity and its own conversation windows. Another person's reply no longer turns Barret, Aerith, Tifa, Red XIII or Hojo into the wrong character.
- Echo-S coverage includes missing named characters, Priscilla at home, added NPCs and fields whose model lists contain unnamed slots.
- Hidden, unavailable and player-controlled actors remain excluded. Party choreography and ladder instructions do not become conversation targets. Normal interaction buttons remain in effect.

Both legacy x86/7th Heaven and Steam x64 are included. Saves, settings, description histories and recordings are preserved.

Automated checks use the supplied ranch log, installed native data and five Echo-S variants. Live traversal, physical controller use and audible speech for this repair remain untested. See the [validation details](../validation/npc-visibility-labels-20261028.md).
