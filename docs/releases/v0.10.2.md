# Blind Soldier 0.10.2

This testing release corrects a confirmed native hook defect that can cause the reported legacy x86 crash when snowboarding starts. Close the game before updating.

The snowboard text renderer uses a native calling convention that the mod's hook did not match. The corrected callback preserves the renderer's owner and arguments and restores the caller's stack correctly. This integration runs with Echo-S enabled or disabled. Snowboarding keeps its existing spoken course cues and normal game controls. Raw font draws stay in diagnostics, preventing flashing menu colours and partial score strings from interrupting those cues with incorrect speech.

Both the legacy x86/7th Heaven and Steam x64 packages are included. Existing saves, player settings, description histories and recordings are preserved.

The native regression reproduces the previous 20-byte stack imbalance. It checks the repaired callback's stack balance and argument forwarding, executes the installed renderer's entry and no-draw exit through the corrected callback, and retains the 601-position course checks. A production-callback replay verifies that raw font draws stay out of generic menu speech. These are automated checks; a live snowboard run, controller use and audible speech remain untested, so live confirmation of the reported crash is still pending.

This release does not add dedicated Gold Saucer snowboard menu, score or record readouts. Those remain a separate accessibility gap.
