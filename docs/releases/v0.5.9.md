# Blind Soldier 0.5.9

This prerelease expands town NPC navigation across both supported game versions. It addresses empty lists such as Costa del Sol Harbor and covers interactions that use sounds, animations, or shop counters instead of ordinary dialogue.

## Changes

- Town NPCs can receive a plain description from their native character model and script identity when their dialogue has no speaker heading.
- Reviewed shopkeepers, counter interactions, and animals are included with their native visibility and interaction requirements. Named companions retain their names.
- Menu options, currency counters, and dialogue spoken over scenery no longer turn into misleading NPC names.
- Costa del Sol's paid return-ship exit is labeled **Board the ship to Junon**. The game's payment and boarding requirements still apply.

## Validation and limits

The audit uses the installed game's model table, character scripts, dialogue, and interaction lines. Regression checks cover discovery, labels, hidden and unavailable actors, and counter targets. Both runtime builds and release packages are checked before publication.

This is a native-data and regression-test audit, not a complete playthrough of every town and story state. Please restart after updating and retest the harbor or any previously empty NPC list. A town-level report is sufficient when accompanied by the log: it records the exact field even when the spoken area name is broad.

## Downloads and updating

- **Blind-Soldier-Portable.zip:** both runtimes, including Steam 2026 x64.
- **Blind-Soldier-2013-x86-Portable.zip:** legacy 2013/7th Heaven x86.
- **ffviinew-v0.5.9-amm.zip** and **ffviiold-v0.5.9-amm.zip:** Accessibility Mod Manager packages.

Each archive has a SHA-256 sidecar. Preserve `Reloaded-II\Mods\ff7.accessibility.reloaded\Configuration\config.json` when updating a portable installation. Restart the game to load the update.
