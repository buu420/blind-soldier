# Blind Soldier 1.0.3

This update adds translated screen-reader descriptions, repairs the Midgar-model
puzzle on Shinra floor 65, and adds an accessible launcher for the original
English Steam 2013 game.

- French, German, Spanish, Japanese and Polish use translated text through the
  screen reader instead of English recordings. This covers rooms, field scenes,
  movies, summons, limits, the ending, credits and post-credits description.
  English keeps its recordings. Existing description settings and history remain.
- Floor 65 Story guidance follows the piece you are carrying to an empty model
  slot, then returns you to the remaining chests and Keycard 66. It handles every
  native chest and placement order. Place pieces with the normal game controls.
- The original 2013 launcher has keyboard and screen-reader access to Play,
  Settings, language, save profile and status. Accessible Play uses local saves;
  the original launcher is backed up and remains available for online features.
  Missing controls settings receive the original launcher's defaults; custom
  bindings are preserved. Original driver notices and its keyboard guide receive
  their native localized text. Existing 7th Heaven launch methods are kept.
- The x86 loader fixes a startup race reproduced with the original 2013 game.
  Stock 7th Heaven, ReShade and the layout without `.local` are preserved.

The five translation catalogs contain 1,615 descriptions each and received an
Opus language review. Native-speaker listening remains unverified. Native script
checks cover the official language versions and reviewed Polish description
triggers; changed Polish navigation remains outside the supported map set.
The original French, German and Spanish 2013 executables are not supported by
the reader. Some original-driver readers require FFNx; the launcher reports this
driver distinction.
Original-driver startup, its keyboard guide and title speech were checked in a
private 2013 copy; full standalone gameplay and saving still need live testing.
