# Blind Soldier 0.1.4

Blind Soldier 0.1.4 introduces a registry-free, direct-extract distribution for
the original Windows PC version of Final Fantasy VII.

## Installation

1. Download `Blind-Soldier-Portable.zip` and its `.sha256` file.
2. Extract every file in the ZIP directly into the Final Fantasy VII game
   folder.
3. Start the game normally from Steam or 7th Heaven.

No installer, administrator access, global .NET installation, or registry
change is required. The archive includes the accessible Steam 2026 launcher,
legacy and converted x86 hooks, 7th Heaven's nested x86 layout, both native
bootstrap architectures, private .NET 9.0.8 runtimes, Reloaded-II 1.30.3,
Reloaded Shared Hooks 1.16.3, Prism, and the dual-runtime Blind Soldier mod.

## Important

- Back up an existing `.local\winmm.dll` before extraction. Do not replace an
  unknown proxy without preserving it.
- Steam 2026 x64 must be started through Steam and the included accessible
  launcher. Starting `FFVII.exe` directly bypasses the accessibility boundary.
- Logs are written under `Blind-Soldier\Logs`.
- The mod remains prerelease software. Current live story validation reaches
  the first arrival on the world map.

The release publishes only the portable ZIP and its SHA-256 sidecar.
