# Blind Soldier 0.5.8

This prerelease addresses the latest Steam 2026 x64 PHS and Status reports, incomplete cutscene description playback, and gaps during the first Gold Saucer visit.

## Changes

- PHS and Status opened from the world map retain menu ownership using their native screen evidence. They no longer depend on the root menu's temporary widget evidence.
- Story now offers the direct Battle Square exit from Wonder Square after Cait Sith joins. The target follows the installed exit geometry and only appears during the relevant first-visit stage.
- The chocobo racing waiting room includes Joe, the other jockeys, and Ester in NPC navigation when they are visible and available to talk. Ester's existing race-start target still waits for her to return.
- Recorded cutscene action descriptions finish when a dialogue box opens; the game's dialogue waits for the recording instead of cutting it off or speaking over it.

## Validation and limits

Regression tests cover world-map menu entry and evidence expiry, the Gold Saucer story stage and native exit, waiting-room visibility and Talk gates, and narration/dialogue ordering. Installed field scripts and Ghidra provide the native interaction evidence. Both architectures and the release packages are checked before publication.

The reporting player still needs to retest in the game after updating and restarting. Leaving a field, losing the game window, or a native film ending or being replaced can still stop a description tied to that scene. This update changes playback behavior and navigation coverage; the recorded voice assets are unchanged.

## Downloads and updating

- **Blind-Soldier-Portable.zip:** both runtimes, including Steam 2026 x64.
- **Blind-Soldier-2013-x86-Portable.zip:** legacy 2013/7th Heaven x86.
- **ffviinew-v0.5.8-amm.zip** and **ffviiold-v0.5.8-amm.zip:** Accessibility Mod Manager packages.

Each archive has a SHA-256 sidecar. Preserve `Reloaded-II\Mods\ff7.accessibility.reloaded\Configuration\config.json` when updating a portable installation. Restart the game to load the update.
