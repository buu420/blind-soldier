# Blind Soldier 0.10.0

During the Kalm flashback, the upstairs Shinra Mansion bookcase now appears in
Objects. Story guides you to the bookcase before offering the stairs behind it.

Use your normal Confirm button at the bookcase to open it. Navigation uses the
game's interaction distance and facing checks. Once the passage opens, Story
guides you down through the right wing. The return journey and present-day
bookcase interaction remain available.

The fix applies to both FFVII runtimes. Native field checks cover stock data and
the five reviewed Echo-S 7 variants. Other optional mansion targets keep their
existing availability rules.

See [validation](../validation/mansion-bookcase-20261013.md) for the native
evidence, regression coverage and testing limits. Live gameplay, controller
input and audible Prism output have not been confirmed for this fix.

Close the game before updating. Saves, settings, narration history and existing
audio-description recordings are preserved. This release adds no recordings.
