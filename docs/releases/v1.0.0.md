# Blind Soldier 1.0.0

- First stable release for the original Final Fantasy VII: current Steam x64 and legacy 2013 x86, including 7th Heaven.
- Includes screen-reader menus, dialogue choices and battles; field, world-map and Story navigation; audio descriptions; and minigame guidance and assists.
- Chocobo race registration now reads each bird's displayed name instead of announcing a blank row. Unavailable or changing name data waits for a coherent read, and genuinely empty rows keep their native behavior.
- Community testers have completed the game and confirmed that the Ancient Forest puzzle is completable.

The registration repair passed full automated tests on both runtimes, stock data and five Echo-S layouts. Its live in-game speech still needs confirmation: register for a race and check each chocobo name and the cancel option.

Close Final Fantasy VII before updating. If you use 7th Heaven, close it as well. Settings and description history are preserved on updates.
