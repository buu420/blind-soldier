# Blind Soldier 0.9.0

This beta adds Story guidance through the late Midgar underground tunnels on
legacy x86/7th Heaven and Steam 2026 x64. Close the game before updating.

- Story explains the entry ladder's normal Up control.
- The reused tunnel screens now give the next passage before the Turks encounter
  and on return visits from either side of the tunnels.
- After the encounter is resolved, Story leads toward the bridge. Fighting or
  declining the encounter remains the player's choice.
- The pickup audit verifies all eleven native pickups and both save points in
  this underground stretch. Objects lists visible, uncollected pickups in the
  current section; optional passages remain available through Exits.

Use the existing navigation controls. The mod reads native chapter, tunnel
section and line state; it does not change progression or reveal pickups in
other sections. Existing settings, saves and description history are preserved.

Automated checks cover both runtimes and their installed field data. Live
gameplay, hardware-controller delivery and listening tests remain unverified
for this repair. See [native validation evidence](../validation/midgar-tunnels-20261010.md).
