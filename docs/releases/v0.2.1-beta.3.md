# Blind Soldier 0.2.1 Beta 3

This prerelease fixes Polish fan-translation dialogue being spoken with symbols
in place of Polish special characters.

## What changed

- Decodes the Polish translation's repurposed FFVII font slots as the matching
  Polish characters in field dialogue and kernel text.
- Automatically recognizes the verified Bunio Polish V1.05 translation font.
- Accepts `pl` or `Polish` as an explicit `GameLanguage` override for compatible
  translation variants.
- Keeps ordinary English data, generated accessibility prompts, and the English
  opening audio-description track working as before.
- Allows an optional `Languages/pl.json` catalog to translate Blind Soldier's
  generated accessibility messages without changing native Polish dialogue.
- Applies the same shared decoder behavior to the legacy x86 and Steam 2026 x64
  backends.

## Testing requested

Use a Polish-translated field dialogue containing letters such as `ą`, `ć`,
`ę`, `ł`, `ń`, `ó`, `ś`, `ź`, or `ż` and confirm Prism announces the letters
instead of unrelated symbols.

## Installation

Two ZIPs are available:

- `Blind-Soldier-Portable.zip` is the complete dual-runtime package for Steam
  2026 x64 or installations that need both x86 and x64 support.
- `Blind-Soldier-2013-x86-Portable.zip` is the smaller package for direct 2013
  x86 or stock 7th Heaven/FFNx.

Close Final Fantasy VII and 7th Heaven, then extract the appropriate ZIP over
the existing Blind Soldier installation. Accessibility Mod Manager users can
install the matching beta update directly.
