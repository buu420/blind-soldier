# Blind Soldier 0.8.1

This testing release repairs Highwind navigation to Icicle Inn and the Great Glacier on legacy/7th Heaven and Steam x64. Close the game before updating.

- Selecting Icicle Inn (North Side) or Great Glacier while flying now finds a legal grass landing near Icicle Inn's south entrance when there is no direct route. Navigation explains the route through town instead of reporting no landing spot.
- Auto walk stops over the landing spot and announces it. **Press Cancel to land manually.** After dismounting, auto walk continues toward Icicle Inn if still enabled. At town, navigation explains the next step; it does not claim you have already reached the Great Glacier.
- The snowboarding slope appears in **Exits** on return visits when the game allows it: Cloud must lead, the snowboard must have been taken, the Glacier Map must have been read, and the slope's trigger must be enabled. Use that exit to start the snowboard run to the glacier.
- If already on foot in the northern snow area, a direct route to Great Glacier remains available. Cancelling or changing targets clears the previous route guidance.

The Highwind still lands only on terrain accepted by the game. Snow is not treated as grass. Existing Great Glacier treasure routes, recordings, and description history support remain included.

## Testing

Automated checks cover both runtimes, the native field scripts and world-map data, manual landing and dismount transitions, later visits, and 54 flight replay cases across the three northern destinations. These checks do not replace a live playthrough. Please test flying to either Icicle Inn entry or Great Glacier, landing and dismounting, walking into town, and selecting the snowboarding slope under Exits.

## Downloads and updating

- **Blind-Soldier-Portable.zip:** Steam x64 portable package, also containing the dual-runtime mod.
- **Blind-Soldier-2013-x86-Portable.zip:** legacy/7th Heaven portable package.
- **ffviinew-v0.8.1-amm.zip** and **ffviiold-v0.8.1-amm.zip:** Accessibility Mod Manager packages.

For a manual ZIP update, back up the entire `Reloaded-II\Mods\ff7.accessibility.reloaded\Configuration` folder, extract the matching ZIP over the game folder, then restore that folder. This preserves settings and description history. Existing recordings and saves are unchanged.
