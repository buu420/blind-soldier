# Blind Soldier 0.5.2 (Beta)

Fort Condor can now be played without a stream of stale coordinates, and the
features added there work on both supported game runtimes.

This is the build Brice played through and won with before release.

## What changed

### Fort Condor

- `I` moves the battlefield cursor to the target selected with the Fort Condor
  navigator. It uses Final Fantasy VII's own configured direction keys rather
  than writing a new position into the game, and says `Moving.` followed by
  `Moving stopped.`.
- Ordering an ally to move says `Moving.` once. The game carries the cursor with
  that unit while it walks; Blind Soldier used to treat every small step as a
  manual cursor move and queued eight or more coordinate lines in three seconds.
  Those intermediate lines are now silent.
- Moving the cursor yourself still reads the complete position and whatever is
  there. A moving unit is described as, for example, `256, 872. Attacker, 180
  of 180. Moving.` If it stops while the cursor remains on it, the same readout
  ends with `Stopped.`.
- A successful order keeps the game's `Arrived at the directed position.`
  report. An interrupted order says where movement stopped instead of ending in
  silence.
- The battle interfaces that used to draw pictures without speaking now read
  their choices and state, including unit commands, destination and direction
  selection, crowded-unit selection, reports, pause, speed, the start prompt
  and help. `P` reports the current battle line.

### Navigation

- Removed the continuous directional audio beacon from field and world-map
  navigation on both runtimes. Field navigation never called its beacon in a
  released build, and the world-map player was constructed without ever being
  given a cue. Blind Soldier's navigation remains speech-first, with spoken
  directions and the configurable progress indicator.
- Proximity sounds for exits, ladders, chests, materia and other nearby objects
  remain. The motorcycle/highway steering cue also remains.
- Removed six beacon and footstep settings that no runtime read.

### Steam 2026 x64 parity

- The x64 runtime now receives the same Midgar Zolom marsh warning,
  suspend/resume announcements, spoken opening-movie description, configured
  field transition cue and Honey Bee Inn exit profiles that were already wired
  on x86.
- The Fort Condor cursor jump, menus and movement readouts use shared code and
  shared regressions on x86 and x64.

### Packaging

- Packages no longer contain `Assets\footsteps\real_samples`, the 2.6 MB source
  archives used while preparing footstep sounds. The sounds used by the mod are
  unchanged. A package assertion prevents those source archives from returning.

## Known limits

- The Steam 2026 x64 runtime still needs general play testing.
- Stock 7th Heaven 4.5.2 can fail before any mod loads with error `0xC000007B`
  in one AppLoader redirection case. Blind Soldier is not involved at that
  point and cannot repair it from inside the game. The loader issue is tracked
  upstream in [7th Heaven issue 413](https://github.com/tsunamods-codes/7th-Heaven/issues/413).
