# Blind Soldier 0.2.1 Beta 1

This prerelease adds the first multilingual Blind Soldier test build for both
the legacy x86 and current Steam x64 versions of Final Fantasy VII.

## What changed

- Adds automatic English, French, German, Spanish, and Japanese detection.
- Reads native menu, dialogue, item, spell, field, and kernel text from the
  active language's FFVII data files.
- Localizes Blind Soldier navigation, battle-status, menu, and accessibility
  messages in all five supported languages.
- Falls back to English for an individual generated message when its
  translation is unavailable, so accessibility information is not omitted.
- Removes English-label dependencies from supported menu readers, including
  title, quit, save/load, Config, Status, Materia tutorial, and party formation
  flows.
- Preserves accented western text and Japanese characters through the speech
  pipeline.
- Adds `GameLanguage` configuration and optional external translator catalogs.

## Testing requested

Please test menus, dialogue, save/load, Config, Materia, title and quit prompts,
field navigation, battle speech, item and spell names, and generated navigation
messages in any available non-English installation. Reports should include the
game language, x86 or x64 runtime, the exact screen or field, and the Blind
Soldier log.

The opening movie's recorded audio-description track remains English in this
test build. Any other untranslated generated description should also fall back
to English rather than remaining silent.

## Installation

Two verified ZIPs are available:

- `Blind-Soldier-Portable.zip` is the complete dual-runtime package for Steam
  2026 x64 or installations that need both x86 and x64 support.
- `Blind-Soldier-2013-x86-Portable.zip` is the smaller package for direct 2013
  x86 or stock 7th Heaven/FFNx. It omits the Steam 2026 launcher and every x64
  runtime component.

Close Final Fantasy VII and 7th Heaven before extraction. For direct Steam
launch, extract the selected ZIP directly into the Final Fantasy VII game
folder. For 7th Heaven, extract the x86 ZIP into the directory containing its
`workingdir` folder. Launch normally afterward. Do not run the bootstrap
executables manually; Blind Soldier does not replace or modify 7th Heaven or
FFNx files.
