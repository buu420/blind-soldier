# Blind Soldier 0.1.0-pre.5

This prerelease completes the public installer rename and repairs the release
channel mismatch introduced when the GitHub repository became Blind Soldier.

- All public release assets now use the Blind Soldier name:
  `Blind-Soldier-Setup.exe`, `Blind-Soldier-Runtime.zip`, and
  `blind-soldier-channel.json`.
- Installer downloads and update checks now validate against the renamed
  `buu420/blind-soldier` repository and matching asset URLs.
- The managed setup executable, logs, and state now live under Blind Soldier
  paths.
- Existing installs under the former name remain discoverable and are migrated
  only after a successful Blind Soldier installation.
- The stable internal Reloaded mod ID remains `ff7.accessibility.reloaded` so
  installed profiles and mod ordering continue to work.

Download `Blind-Soldier-Setup.exe` for the standard screen-reader-accessible
installation. The installer is not code-signed yet, so Windows SmartScreen may
identify the publisher as unknown.
