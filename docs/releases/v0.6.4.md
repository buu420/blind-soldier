# Blind Soldier 0.6.4

This prerelease repairs Shinra Mansion navigation and includes room-description and Cosmo Canyon auto-walk fixes for legacy x86/7th Heaven and Steam 2026 x64.

- Restores the missing secret-passage exit in the x64 mansion Exits list while preserving the game's locked-door requirements.
- Restores spoken navigation to the safe and piano, adds the opened-chest clue and floor-search targets, and provides an approach to the secret panel that must be opened with OK.
- Gives mansion wings, doors, stairs and basement passages distinct exit labels.
- Remembers automatic room descriptions once per save file across restarts. Tracking begins with this update; previously heard rooms cannot be recovered retroactively. Keep the entire mod Configuration folder when updating, including room-descriptions.json.
- Preserves the auto-walk target across battles and temporary loss of focus, and releases movement while play is suspended.
- Repairs running clearance checks near walls and the narrow upper Cosmo Canyon connector in both directions.

Automated tests cover the native mansion scripts, locked-panel behavior, Vincent interaction availability and routes through the mansion on both runtimes. The complete Vincent recruitment sequence has not been played through live with this build. Two reported mansion auto-walk stalls remain unreproduced; please report any remaining stuck positions.

Existing movie and cutscene narration is preserved. This release adds no new recordings.

## Downloads

- **Blind-Soldier-Portable.zip:** both supported game runtimes.
- **Blind-Soldier-2013-x86-Portable.zip:** legacy 2013/7th Heaven x86.
- **ffviinew-v0.6.4-amm.zip** and **ffviiold-v0.6.4-amm.zip:** Accessibility Mod Manager packages.

Each archive has a SHA-256 sidecar. Preserve the Reloaded-II\Mods\ff7.accessibility.reloaded\Configuration folder when updating a portable installation. Restart the game after updating.
