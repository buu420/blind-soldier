# Blind Soldier v0.1.6

## Stock 7th Heaven bootstrap

Blind Soldier v0.1.6 works with a normal official or source 7th Heaven
installation. No special 7th Heaven build is required.

- The x86 path uses the executable-specific `.local\version.dll` Version proxy.
  The ZIP contains exactly four byte-identical copies: one for each supported
  x86 executable layout.
- The accessible launcher uses the stock AppLoader boundary; it does not replace
  7th Heaven's launcher or FFNx runtime.
- Prism remains bundled for screen-reader speech in the x86 and x64 mod paths
  and the accessible launcher.
- Blind Soldier does not ship, install, replace, or overwrite FFNx. Official
  7th Heaven manages its own FFNx installation.
