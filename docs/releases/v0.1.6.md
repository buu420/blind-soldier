# Blind Soldier v0.1.6

## Stock 7th Heaven bootstrap

Blind Soldier v0.1.6 is verified with the official stable 7th Heaven 4.5.2
release. No special 7th Heaven build is required. Development builds targeting
.NET 10 are outside this release's verified compatibility set.

- The x86 path uses the executable-specific `.local\version.dll` Version proxy.
  The ZIP contains exactly eight byte-identical copies covering the supported
  direct and 7th Heaven x86 executable layouts.
- The accessible launcher uses the stock AppLoader boundary; it does not replace
  7th Heaven's launcher or FFNx runtime.
- Prism remains bundled for screen-reader speech in the x86 and x64 mod paths
  and the accessible launcher.
- Blind Soldier does not ship, install, replace, or overwrite FFNx. Official
  7th Heaven manages its own FFNx installation.
- To roll back, close FFVII, read `portable-manifest.json` from this ZIP, and remove only the Blind Soldier files named in that manifest. Restore any launcher or `.local\version.dll` you backed up before extraction.

## Accessibility fixes

- Restores resilient MESSAGE and ASK dialogue detection under FFNx.
- Repairs Church and Sector 6 park story-objective progression.
- Adds the first-reactor elevator switch to the Objects category.

## Optional Amethyst registry cleanup

The ZIP root now includes `Remove-Amethyst-Registry-Entries.cmd`. Run it only
when removing an older Amethyst Mod Manager installation. It requests
administrator access, checks both 32-bit and 64-bit registry views, and removes
only Blind Soldier debugger launch values for `ff7_en.exe` and `FFVII.exe`.
Unrelated debugger registrations and other values are preserved.

This cleanup is not needed for a normal portable installation and it does not
remove game files, 7th Heaven, FFNx, Steam settings, or save data.
