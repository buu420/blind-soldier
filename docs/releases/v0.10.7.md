# Blind Soldier 0.10.7 beta

Repairs the Winding Tunnel approach to Shinra HQ during the Disc 2 return to Midgar.

- Tunnel ends sealed by the current screen's native section no longer appear as usable exits. This removes the blocked route that sent the reported player around the tunnels.
- The available HQ entrance is labelled "Ladder up toward Shinra HQ" in Exits and retains its native mount and climb guidance.
- Ladder proximity cues stay silent where the game hides that ladder. Its incoming top landing no longer produces a second misleading entrance cue.
- The subway return ladder remains available, including Echo-S's shifted entity layout. Existing main-story guidance and normal action/climbing buttons are preserved.

Both runtimes advance to 0.10.7. Saves, settings, description histories and existing recordings are preserved. Native-data and automated checks cover both runtimes and five Echo-S variants; live traversal, physical controller use and audible screen-reader feedback have not been tested in this development session.

See the [native evidence and validation scope](../validation/winding-tunnel-hq-20261101.md).
