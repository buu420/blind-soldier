# Blind Soldier 0.5.1 (Beta)

Nothing changes in play. This release exists so that the packages people
install are the first ones built under the guards added after 0.5.0's launcher
fix, and so the Mod Manager offers a build made that way.

## What changed

### Under the hood

- The launcher crash that 0.5.0 fixed can no longer come back unnoticed. 0.4.1
  shipped a launcher whose description of Prism's configuration block was one
  byte where the speech library expected thirty-two, and every copy closed on
  startup. That description is now held to the mod's, to a pinned size on both
  x86 and x64, and - for the first time - round-tripped through the actual Prism
  DLL each of the three executables ships: the accessible launcher, the 2013
  runtime and the 2026 runtime. A mismatch now fails the build, fails every
  push, and fails the release, before it can reach anyone.
- Every push and pull request is now checked, not only release tags. Until now
  nothing ran on a merge, so a stale branch could have brought the broken
  launcher back and nobody would have known until the next release.
- The release gate runs the x86 Prism check on the path it actually takes on a
  build machine. It had been placed in a suite that only runs where a licensed
  copy of the game is present, which a build machine never has.

## What did not change

- Nothing a player hears or does. Fort Condor, the launcher, field navigation
  and everything else behave exactly as in 0.5.0.
- The Prism speech library is the same 0.18.0 build on all three executables.

## Known limits

- Unchanged from 0.5.0: the Fort Condor advance gauge is reported at quarters,
  and ten of the fort's unit-name slots read "dummy" because that is the label
  the game draws.
- The Steam 2026 x64 runtime still needs general play testing.
