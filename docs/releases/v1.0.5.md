# Blind Soldier 1.0.5

Adds Russian support for the [ayumosa 7th Heaven translation](https://github.com/ayumosa/ff7-7h-russian), version 1.02.

- Reads the translation's Cyrillic game text, character names, menus and choices.
- Provides Russian Blind Soldier menus, navigation prompts and audio-description text. Russian descriptions use the screen reader instead of the English voice recordings.
- Adapts navigation and description triggers to the translation's changed field scripts, including the Northern Crater and Ancient Forest.

Install the Russian translation through 7th Heaven and use a Russian screen-reader voice. Blind Soldier detects the translation's active text encoding; its language setting accepts `ru`, `ru-RU` and `ru_RU`.

Both Blind Soldier runtimes are included. The linked translation is a 7th Heaven mod; this release does not establish that its IRO runs on the native Steam 2026 game.

Automated checks cover both runtime backends, Russian game-data fixtures, the navigation catalogue and all 1,615 description texts. Live Russian gameplay, controller use and screen-reader pronunciation remain for testers to confirm. Please include the game log and affected room or menu with reports.

Update through Amethyst Mod Manager, or use the portable ZIP appropriate to your game. Existing saves and settings are preserved.
