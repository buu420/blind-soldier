# Blind Soldier 0.6.8

This prerelease adds Wutai's materia-recovery quest guidance and menu gil speech for legacy x86/7th Heaven and Steam 2026 x64.

- Adds Story targets through Wutai's materia-recovery sequence, from the required pub conversation and shop chest through the pursuit, trap, bell passage, rescue, and return. Targets follow the game's quest flags.
- Makes the shop chest available after its prerequisite conversation and removes it when opened. Before that conversation, Story points toward the next required step.
- Corrects the shaking-pot interaction, the bell and hidden-room entrance's availability, and navigation back through the hanging scroll.
- Announces gil when opening the main menu or shop screens that display the balance. Press **G** to repeat it while one of those screens is open.

Both full runtime suites passed against the packaged mod DLLs. Wutai checks cover quest-stage transitions, native script conditions, and 75 route replays with scripted obstacles. These checks use installed game data; a live playthrough of the quest is still needed. This update does not certify that every optional Wutai activity or the whole game is completable.

## Downloads

- **Blind-Soldier-Portable.zip:** both supported game runtimes.
- **Blind-Soldier-2013-x86-Portable.zip:** legacy 2013/7th Heaven x86.
- **ffviinew-v0.6.8-amm.zip** and **ffviiold-v0.6.8-amm.zip:** Accessibility Mod Manager packages.

Each archive has a SHA-256 sidecar. Preserve the entire Reloaded-II\Mods\ff7.accessibility.reloaded\Configuration folder when updating a portable installation, including room-descriptions.json. Restart the game after updating.
