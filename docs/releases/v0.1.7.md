# Blind Soldier 0.1.7

Blind Soldier 0.1.7 is a beta startup-reliability update for the Steam 2026
x64 game.

- Fixes an intermittent launch failure where the bootstrap exited with code 17
  and logged that `KERNEL32.DLL` was not found.
- Waits for the resumed game's Windows module list to become ready, using fresh
  snapshots for up to five seconds instead of failing after one incomplete
  snapshot.
- Stops immediately if the game exits and preserves Blind Soldier's fail-closed
  behavior when accessibility cannot be loaded.
- Keeps the existing legacy x86, Steam 2026 x64, accessible launcher, bundled
  Reloaded runtime, FFNx compatibility files, and private .NET runtimes.

The Steam 2026 x64 backend remains beta software. Reports should include the
newest file from `Blind-Soldier\Logs`.
