# Blind Soldier 0.2.4 (Beta)

This beta release repairs field-objective recovery after collecting an item and
makes active ladder routes respond immediately when the player reverses climb
direction.

## What changed

- Restores a useful navigation category after a tracked object disappears. For
  example, collecting the Phoenix Down in Mako Reactor 5 no longer leaves the
  player in an empty Objects category with every objective apparently gone.
- Selects the first currently available category in this order: Story, Exits,
  NPCs, then any other populated category.
- Detects when a route is started while already mounted on a ladder and the
  route requires climbing in the opposite direction.
- Gives the active route immediate ownership of the ladder direction, so
  turning back no longer produces a repeating Down, Up, Down, Up loop.
- Applies the same shared navigation behavior to the legacy 2013 x86 and Steam
  2026 x64 runtimes.

## Testing requested

In Mako Reactor 5, track the Phoenix Down, collect it, and confirm navigation
moves to an available Story or Exit target instead of leaving every category
empty.

On any ladder, start a route, climb past the intended direction, reverse, and
confirm Blind Soldier immediately gives the correct climb direction without
looping between opposite instructions.

## Installation

Two ZIPs are available:

- `Blind-Soldier-Portable.zip` is the complete dual-runtime package for Steam
  2026 x64 or installations that need both x86 and x64 support.
- `Blind-Soldier-2013-x86-Portable.zip` is the smaller package for direct 2013
  x86 or stock 7th Heaven/FFNx.

Close Final Fantasy VII and 7th Heaven, then extract the appropriate ZIP over
the existing Blind Soldier installation. Accessibility Mod Manager users can
install the matching beta-channel update directly.
