# Blind Soldier 0.9.5

Emerald Weapon now uses its checked native draw position for both visibility and
its Events target. Its patrol can move between the entity scan and draw scan;
that motion no longer removes an otherwise visible target or leaves navigation
using an older position. Hidden, off-screen, faded and unconfirmed targets are
still excluded. Selecting Emerald permits pursuit; ordinary submarine routes
retain avoidance, and encounters use normal game controls.

Keyboard accessibility input now has a small independent observer so completed
presses survive slower field/world scans. Navigation, repeat, party queries and
F11 settings keep their existing keys. Queued commands retain order within their
active owner, and each press is delivered once. Focus loss, native field/map or
settings changes, suspension, unload and expired observations retire queued
input and rebaseline held keys. Normal keyboard and controller game input use
their existing paths.

The supplied log confirms the tester loaded 0.9.4. This patch repairs the
logged moving-Emerald mismatch and a separately reproduced keyboard tap-loss
mechanism. The log does not establish whether ordinary game keys also failed;
input diagnostics now identify observer availability, slow sampling and accepted
accessibility presses. Live gameplay, hardware keyboard/controller response and
screen-reader listening still need player confirmation.

Both legacy 2013/7th Heaven x86 and native Steam 2026 x64 are included. Close the
game before updating. Existing settings, saves, description history and narration
are preserved by the deployment workflow.
