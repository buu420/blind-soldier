# Blind Soldier 0.10.3

This testing release repairs navigation in Cosmo Canyon's Huge Materia display. Close the game before updating.

- Stored Huge Materia appear by their visible **green, yellow, red or blue** colour in **Objects**, with a separate target for each available stand. They remain available for repeat visits and no longer appear as repeated Story objectives.
- **Exits** offers **Go back down** through each available stand. Select an approach, walk into the Materia, then choose **Go back down** in the game's menu. Navigation states that choice. The unreachable doorway from the ordinary observatory is removed from this display's list.
- During the initial storage visit, **Story** offers one departure objective while Bugenhagen is waiting to leave. It disappears when the native departure completes.

The display uses a menu to return downstairs; it has no walkable doorway. The game handles the return and any associated Bugenhagen scene. Normal choice and Confirm buttons remain under the player's control.

Steam's spatial object sounds now accept these named Materia objects, matching their shared Objects entries.

Both legacy x86/7th Heaven and Steam x64 packages are included. Native script checks cover both installed archives and five Echo-S variants, including their different choice line numbers. Automated checks cover the seven reported stalled positions, contact arrival and object availability. Live traversal, physical controller use and audible speech for this repair remain untested.

Existing saves, settings, description histories and recordings are preserved. See the [validation details](../validation/observatory-storage-20261020.md).
