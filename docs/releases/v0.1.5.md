# Blind Soldier 0.1.5

Blind Soldier 0.1.5 makes the direct-extract release self-contained for the
supported 7th Heaven converted-game layout.

## Installation

1. Download `Blind-Soldier-Portable.zip` and its `.sha256` file.
2. Close Final Fantasy VII and 7th Heaven.
3. Extract every file in the ZIP directly into the Final Fantasy VII game
   folder.
4. Start the game normally from Steam or 7th Heaven.

No installer, administrator access, global .NET installation, registry change,
or separate FFNx download is required.

## Changes

- Bundles the official FFNx 1.24.3.0 Steam runtime under `ff7\workingdir`,
  where 7th Heaven's converted x86 game expects it.
- Keeps FFNx out of the native Steam 2026 root so that runtime is not replaced.
- Omits the 133 MB FFNx debug-symbol file, which is not required to play.
- Fixes the x86 proxy-to-bootstrap ready-event contract so Blind Soldier can
  attach after FFNx starts the converted game.
- Includes FFNx's GPLv3 license and locked source/archive provenance.

The release publishes only the portable ZIP and its SHA-256 sidecar.
