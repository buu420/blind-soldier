# Blind Soldier 0.9.2

This beta fixes Emerald Weapon tracking underwater on legacy x86/7th Heaven
and Steam 2026 x64. Close the game before updating.

- Emerald is announced and appears in Events when the current rendered view
  confirms it is visible. Select it with the existing navigation controls to
  track its moving position and automatically approach it.
- A camera-memory layout error previously rejected genuine visible sightings.
  The shared reader now reads the native packed camera translation correctly.
- Pursuit pauses immediately when visibility cannot be confirmed, and stops
  after a sustained loss. Other submarine journeys retain Emerald avoidance.
  Encounter handling remains the game's own; no battle input is added.

Settings, saves, audio descriptions and description history are preserved.
Automated checks cover native camera frames, installed underwater geometry,
selection, patrol tracking, visibility loss and ordinary-route avoidance in
both runtimes. Live gameplay, hardware-controller delivery and speech listening
remain unverified for this repair. See the
[native validation evidence](../validation/emerald-tracking-20261010.md).
