# Blind Soldier 0.10.15 beta

This fixes startup crashes caused by executable `.local` folders shipped in older Blind Soldier builds. The x86 packages load Blind Soldier through `version.dll` beside the game executable. They can use the .NET 10 runtime loaded by stock 7th Heaven 4.6.1 or the bundled .NET 9 runtime for standalone launches. Startup through the title menu was tested with ReShade 6.8.0 on and off.

## Updating an existing 7th Heaven install

1. Close Final Fantasy VII and 7th Heaven.
2. In the folder containing `ff7_en.exe` or `ff7.exe`, look for `ff7_en.exe.local` and `ff7.exe.local`. Back up any old Blind Soldier `version.dll` files inside them, then remove the folders if Blind Soldier created them and they are empty. Keep any files used by other mods.
3. Install the update through Accessibility Mod Manager or the 2013 x86 portable ZIP. Keep the `version.dll` beside the game executable.
4. If Play still fails, restart Windows once to clear cached DLL redirection and try again.

The update is available for the 2013 x86 game and Steam 2026 x64.
