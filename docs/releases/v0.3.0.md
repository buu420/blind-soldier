# Blind Soldier 0.3.0 (Beta)

This beta improves native menu and dialogue coverage on both supported FFVII
runtimes, completes more of the Nibelheim flashback, and repairs mounted
world-map accessibility.

## What changed

- Restores Steam 2026 x64 Save-slot and save-file speech when Save is opened
  from the world map without letting unrelated world-map overlays take menu
  ownership.
- Prevents an older blocked field MESSAGE callback from repeating stale NPC
  dialogue over a newer line, while restoring the older visible line if the
  newer overlapping window closes first.
- Reads the Item command row, Arrange choices, manual-sort inventory, Magic
  category, Limit-level confirmation, and normal PHS party-selection screens
  from their checked native state on both runtimes.
- Corrects cursorless Quit confirmation speech and preserves Continue save-file
  selection when the outer prompt is redrawn.
- Reads battle inventory objects from the game's complete object namespace,
  includes their descriptions, and announces when a gray row is unavailable in
  battle.
- Recognizes both live ridden-Chocobo models for world-map routes, terrain
  checks, and the slower mounted footstep cadence.
- Adds the remaining Nibelheim flashback Story objectives through the burning
  town and reactor, labels verified visible NPCs, and excludes invisible event
  proxies from the NPC list.
- Adds missing visual descriptions for the Mt. Nibel reactor reveal and Tifa's
  confrontation with Sephiroth.

## Testing requested

On Steam 2026 x64, open Save from the world map and confirm the save files and
slots speak. Advance through rapid or overlapping NPC dialogue and confirm each
new line speaks once without an older line interrupting it.

On either runtime, check Item Arrange and manual sort, Magic categories, the
Limit-level confirmation, PHS, Quit, and gray battle-item rows. On the world
map, mount a caught Chocobo and confirm footsteps and navigation remain active.

## Installation

Two ZIPs are available:

- `Blind-Soldier-Portable.zip` is the complete dual-runtime package for Steam
  2026 x64 or installations that need both x86 and x64 support.
- `Blind-Soldier-2013-x86-Portable.zip` is the smaller package for direct 2013
  x86 or stock 7th Heaven/FFNx.

Close Final Fantasy VII and 7th Heaven, then extract the appropriate ZIP over
the existing Blind Soldier installation. Accessibility Mod Manager users can
install the matching beta-channel update directly.
