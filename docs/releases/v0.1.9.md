# Blind Soldier 0.1.9

Blind Soldier 0.1.9 is a beta startup-compatibility update for both supported
Final Fantasy VII runtimes.

- Fixes stock Steam 2013 startup by installing the x86 Version proxy directly
  beside `ff7_en.exe` in the mod-manager package.
- Preserves mapped-drive aliases after validating their canonical targets so
  Reloaded can discover Blind Soldier and Shared Hooks on mapped game drives.
- Keeps the Steam 2026 x64 and Steam 2013 x86 package layouts isolated.
- Does not modify Final Fantasy VII, 7th Heaven, FFNx, or the Windows registry.

The Steam 2026 x64 backend remains beta software. Reports should include the
newest file from `Blind-Soldier\Logs`.
