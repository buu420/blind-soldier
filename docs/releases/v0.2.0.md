# Blind Soldier 0.2.0 Beta

Blind Soldier 0.2.0 is a beta Wall Market accessibility update for both
supported Final Fantasy VII runtimes.

- Makes the Wall Market squat minigame announce `Switch`, `Cancel`, and `OK`
  when the corresponding visual input cue becomes active.
- Reads the minigame's native field-script state instead of estimating the
  sequence from elapsed time or sound effects.
- Keeps prompts synchronized across unreadable frames and resets them only
  after the game coherently leaves the minigame.
- Enables squat prompts by default in both the legacy x86 and Steam 2026 x64
  runtimes.
- Does not modify Final Fantasy VII, 7th Heaven, FFNx, or the Windows registry.

The Steam 2026 x64 backend remains beta software. Reports should include the
newest file from `Blind-Soldier\Logs`.
