# Blind Soldier 0.8.11

This beta repairs world-map tracking and piano accessibility on legacy
x86/7th Heaven and Steam 2026 x64. Close the game before updating.

- Ultimate Weapon remains selectable when its live flying position is above a
  field entrance. Highwind pursuit follows its current position and reacquires
  its native identity after battle. If it is no longer in a valid native list,
  navigation stops and explains why. An unreadable list pauses flight until a
  fresh read; cancelling or replacing the destination cancels the pending chase.
- Northern Crater guidance routes toward the native entry point. A distant
  position can no longer count as arrival through cancelling coordinate offsets.
  Height still matters, and landing uses the normal game control.
- Spoken field instructions now name the native Start, shoulder and direction
  buttons correctly, including the instructions for ending a piano performance.
- During performances at Tifa's piano and the Shinra Mansion piano, the mod
  passes notes, octave shifts, chords and Start to the game. Held menu presses
  drain until release; new piano presses pass immediately. R3 remains reserved
  to prevent the Steam Battle Assist shortcut.

The repairs use the game's native world entities, entry conditions and piano
script threads. They do not change save progression, Weapon health or piano
notes. Existing settings, saves and description history are preserved.

Automated regression and release checks cover both runtimes. Live gameplay,
hardware-controller delivery and listening tests remain unverified for these
repairs. See [native validation evidence](../validation/world-weapon-crater-piano-20261009.md).
