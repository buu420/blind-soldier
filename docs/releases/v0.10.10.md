# Blind Soldier 0.10.10 beta

Emerald Weapon is selectable in underwater Events as soon as its native entity is active. Its position updates through fog and outside the camera view, including before the first sighting. Select it and start navigation if you want to approach it. Ordinary submarine travel keeps its usual depth and reports Emerald's proximity at a manual descent. Sighting announcements still describe what is visible.

For the Key to Sector 5, talk to the man at Midgar's entrance who mentions losing his key on an excavation tour. In Bone Village, use Story to find the foreman. Set up the excavation with the normal game controls, then select the key dig site in Story when the game asks where to dig. On return, Story leads to the results chest. Open it with Confirm. The objective disappears once the key is collected.

The original conversation leaves no saved flag. If you heard the clue before installing this update, talk to the man again and save to keep the clue for that playthrough. The foreman and clue work with the five reviewed Echo-S layouts.

Close the game before updating. See the [native evidence and validation scope](../validation/emerald-key-sector5-20261104.md).
