# Blind Soldier 1.0.1

This update repairs Echo-S dialogue speech and adds description controls,
the missing Honeybee Inn lobby description, and the supplied GOG compatibility changes.

- Prism no longer reads the decorative not-equal marker before a dialogue speaker's name.
  Cleanup happens only at speech output, preserving native page and scene matching.
- The verified FFNx 1.25.2 voice hook suppresses duplicate field dialogue, including the
  optional drawing fallback. Unvoiced lines, missing recordings and choices stay readable.
- **Read voiced dialogue** in F11 settings lets you turn duplicate speech back on.
  It starts off and your choice is saved.
- **Reset battle descriptions for this save**, the second F11 setting, covers every
  limit break, summon and summoning introduction. The new third setting, **Reset all
  descriptions for this save**, also resets room arrivals. Activate twice to confirm;
  descriptions replay at their next occurrence and other saves keep their histories.
- Honeybee Inn's lobby now has a scenery description in Brice's existing narration voice.
  Audio descriptions generated with [ViddyScribe](https://viddyscribe.com); the draft was
  reviewed against the native room artwork and edited before recording.
- The dual-runtime portable package now recognizes the contributed GOG x64 executable
  identity and keeps GOG settings and save paths separate from Steam's. Keep the game's
  GOG metadata file beside the accessible launcher.

GOG launch and live save/menu behavior still need tester validation: no GOG game install
was available for these checks. Executable and native code guards remain enabled.
The existing stock 7th Heaven/ReShade loader layout is retained, without `.local` folders.

Open spoken settings with F11, or hold both controller triggers and press Y/Triangle.
Keyboard: J/L selects a setting, I activates; controller: D-pad selects, A/Cross activates.
