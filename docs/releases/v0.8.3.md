# Blind Soldier 0.8.3

This beta update improves Gold Saucer menus on both runtimes and connects the
submarine accessibility reader in Steam x64. Close the game before updating.

- **GP seller:** reads the selected GP quantity and its gil cost as they change.
- **Battle Square:** reads the highlighted Continue/Quit choice between rounds,
  current BP, the start of the handicap slot and the stopped handicap. Registration
  retains the visible current GP window; x64 no longer repeatedly interrupts the
  question with that companion window. Dialogue resolves current party names.
- **Controller navigation in Steam x64:** reserves R3 consistently, including
  busy scenes and multiple controllers, to prevent the known Battle Assist shortcut
  collision. Native controller shortcuts that use R3 are also reserved. Keyboard
  F1/F2/F9 and the game's Boosts settings remain available.
- **Submarine in Steam x64:** adds spoken native instruments and visible targeting
  information, the lock sound and K to repeat the current readout. Entering the
  mission releases field navigation input. Steering and firing remain manual.

## What still needs testing

The reported freeze after Cloud says “We're gettin' outta here!” is **not a
confirmed fix**. This update records a bounded, read-only trace after leaving the
submarine mission so a new log can show where Confirm stops advancing the scene.
If it happens again, send the log from this version, including the mission exit.

The supplied Pagoda log predates the current routes. Checks cover all five floors,
stair locks, wins, losses and Godo's reset; no new route defect was reproduced.
If progressing between opponents still fails, send a fresh log from 0.8.3.

Automated checks cover both runtimes and the packaged files. Live submarine,
controller and Battle Square testing is still needed. The native executable used
for static verification is the saved matching licensed copy; the incomplete local
Steam installation does not allow a live x64 gameplay check.

Existing narration, description history and user settings are preserved.
