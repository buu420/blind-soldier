# Blind Soldier 0.7.5

This testing release repairs the Bone Village foreman approach, Corel Valley Cave navigation, and Steam x64 controller-menu timing. Restart the game after updating.

## Changes

- **Bone Village:** the NPC list identifies the Excavation foreman, and autowalk can approach him within the game's normal talking distance. NPC and Story targets are checked from the world-map entrance, Sleeping Forest entrance, and return from digging.
- **Corel Valley Cave:** routes now follow the vines' actual final landings, including routes through the cave, to all four treasures, and back out. Climb prompts announce the required junction answers, including two answers when needed. Select those answers using the game's normal dialog controls.
- **Controller navigation on Steam x64:** corrected timing that could close the navigation menu before a bumper press was handled. The mod also hands buttons back promptly when a native dialog, scene, or control lock takes over.
- **Ladder cues:** each physical entrance gives one proximity cue. Equivalent climb routines preserve their valid party-leader conditions.

## Testing

Both runtime suites, shared and parity checks passed against the packaged mod. Independent checks against both installed archives cover all 32 completed cave outcomes, their required answers, and 42 routes per archive. The x64 controller tests include R1, L1, autowalk, delayed worker updates, and native-input handoff. Existing field-catalog coverage, exit definitions, and NPC definitions are preserved.

These are automated checks. The repaired behavior still needs an in-game retest, and this release does not certify a complete playthrough. Please test the foreman, the cave's exits and treasures, its spoken vine choices, and controller category changes.
