# Blind Soldier 0.7.9

This testing release adds treasure routes across the Great Glacier for legacy x86 and Steam x64. Close the game before updating.

## Great Glacier treasures

- **Objects throughout the region:** Mind Source, Potion, Safety Bit, Elixir, Added Cut, All and Alexander remain listed until collected, including from Holzoff's cabin and the snowfield. Items elsewhere are identified as regional targets; an item already visible on the current screen keeps its local entry without a duplicate.
- **Routes across screens:** selecting a regional item plans a route by estimated walking distance, rather than the fewest screen changes. The chosen destination carries across fields, the snowfield, battles and the Glacier Map. The game's pickup flags remove collected items.
- **Required interactions:** Alexander's route includes touching the hot spring, talking to and defeating Snow, and collecting the materia. The Safety Bit route guides you to the ice-floe crossing, where the puzzle still requires your input.
- **Exhaustion and control:** after an exhaustion collapse, the selected treasure is retained and auto walk pauses until you resume it. Cancelling navigation or selecting another target ends the previous route. The game's exhaustion mechanic is unchanged.
- **Passage movement:** routes can leave a locked triangle the game has already placed the character on, matching native movement rules, while still refusing entry into locked triangles.

## Testing and remaining limits

Installed-data checks cover all 164 native arrival positions, the seven treasures and Alexander's prerequisite stages. Controller checks cover screen changes, repeated snowfield entrance samples, map and battle suspension, collection flags, cancellation and exhaustion recovery. The release also undergoes the automated dual-runtime, packaging, native-loader and Ghidra checks against the published archives.

These checks do not replace a live playthrough. Please test routes from the cabin to the treasures in both game versions, especially passage reloads, snowfield entrances and the Snow battle return. Route costs estimate ordinary walking; slopes, Run, encounters and loading can change the actual trip. Ice-floe puzzle input remains manual.

## Downloads and updating

- **Blind-Soldier-Portable.zip:** Steam x64 portable package, also containing the dual-runtime mod.
- **Blind-Soldier-2013-x86-Portable.zip:** legacy/7th Heaven portable package.
- **ffviinew-v0.7.9-amm.zip** and **ffviiold-v0.7.9-amm.zip:** Accessibility Mod Manager packages.

For a manual ZIP update, back up the entire `Reloaded-II\Mods\ff7.accessibility.reloaded\Configuration` folder, extract the matching ZIP over the game folder, then restore that folder. This preserves settings and description history. Existing recordings and saves are unchanged.
