# Blind Soldier 0.2.3 (Beta)

This beta release repairs Continue-menu speech and makes automatic Polish
translation detection survive an overwritten or unavailable font file.

## What changed

- Keeps the visible Continue save-file grid readable while its native
  availability state is temporarily refreshing.
- Reads the selected save file without inventing whether an unreadable file is
  empty; native preview details are still spoken as soon as they become
  available.
- Detects the Bunio Polish translation from its translated `kernel2.bin` when
  `WINDOW.BIN` has been replaced or hidden by another game modification.
- Selects the Polish decoder before Steam's English manifest fallback, so
  letters such as `ą`, `ć`, `ę`, `ł`, `ń`, `ś`, `ź`, and `ż` reach Prism as
  Polish characters instead of unrelated symbols.
- Uses the same shared language detector for the legacy x86 and Steam 2026 x64
  backends.

## Testing requested

With `GameLanguage` set to `auto`, start a Polish-translated game and confirm
the Blind Soldier log reports `Polish (pl)`. Check dialogue, Config help text,
and item descriptions containing Polish special characters.

Open Continue, move through the save-file grid, enter a file, and back out.
Confirm the file number and available save preview speak without a long silent
period.

## Installation

Two ZIPs are available:

- `Blind-Soldier-Portable.zip` is the complete dual-runtime package for Steam
  2026 x64 or installations that need both x86 and x64 support.
- `Blind-Soldier-2013-x86-Portable.zip` is the smaller package for direct 2013
  x86 or stock 7th Heaven/FFNx.

Close Final Fantasy VII and 7th Heaven, then extract the appropriate ZIP over
the existing Blind Soldier installation. Accessibility Mod Manager users can
install the matching beta-channel update directly.
