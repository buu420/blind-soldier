# Blind Soldier 0.6.3

This prerelease adds spoken Shinra Mansion safe-dial numbers to both legacy x86/7th Heaven and Steam 2026 x64.

- Reads the visible dial number while turning, with bounded updates and a final update when the dial stops.
- Left/Right turns the dial and OK confirms the number, using the game's existing controls.
- Prevents blank numeric-window speech and keeps the countdown from interrupting the dial numbers. The countdown remains silent while the dial is active.
- Prevents stale dial numbers after an unavailable memory read, and resumes current-number speech when speech is re-enabled.

Only the number shown by the game is read. The combination, correct direction and puzzle solution are not announced. Safe readout uses the existing Field Activity Readout setting. Use normal game speed for this timed puzzle.

Both full runtime test suites and focused safe-dial checks passed. Native field scripts were checked against both installed game archives. Live safe gameplay confirmation is still needed.

Existing navigation and narration are preserved. This release adds no new recordings.

## Downloads

- **Blind-Soldier-Portable.zip:** both supported game runtimes.
- **Blind-Soldier-2013-x86-Portable.zip:** legacy 2013/7th Heaven x86.
- **ffviinew-v0.6.3-amm.zip** and **ffviiold-v0.6.3-amm.zip:** Accessibility Mod Manager packages.

Each archive has a SHA-256 sidecar. Preserve `Reloaded-II\Mods\ff7.accessibility.reloaded\Configuration\config.json` when updating a portable installation. Restart the game after updating.
