# Blind Soldier 0.6.0

This prerelease adds descriptions across more of the game and improves navigation around Cosmo Canyon and world-map entrances. It supports both the legacy x86 and Steam 2026 x64 versions.

- **220 new recordings in Brice's voice**, totaling about 22 minutes. These cover 218 area-arrival descriptions and nine story-action cues, from Gongaga and Cosmo Canyon through later regions, with some recordings shared between cues. The packaged short-clip total is now 838.
- **World-map routes avoid unrelated location entrances.** Approaching the Buggy near Gongaga no longer deliberately routes through the jungle entrance. The selected destination's entrance remains usable. Navigation reports when it cannot find a safe route.
- **Cosmo Canyon exits remain selectable while a script holds them closed.** Navigation explains the delay and retains the requested destination. An autowalk request can resume when the route opens; spoken guidance does not turn into autowalk. Cancelling or changing the target discards the held request.
- Existing movie narration and all 618 previously released short recordings are unchanged.

The description and navigation changes were checked with automated tests and the installed game's native data. They still need live play-testing. This is not complete cutscene coverage: some animated actions still need visual verification or additional runtime support. No new FMV narration is included in this release.

## Downloads

- **Blind-Soldier-Portable.zip:** both supported game runtimes.
- **Blind-Soldier-2013-x86-Portable.zip:** legacy 2013/7th Heaven x86.
- **ffviinew-v0.6.0-amm.zip** and **ffviiold-v0.6.0-amm.zip:** Accessibility Mod Manager packages.

Each archive has a SHA-256 sidecar. Preserve `Reloaded-II\Mods\ff7.accessibility.reloaded\Configuration\config.json` when updating a portable installation. Restart the game after updating.

Version numbering continues from 0.6.0 through 0.6.9, then 0.7.0. The patch number will not exceed 9.
