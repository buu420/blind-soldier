# Blind Soldier 0.5.6

This prerelease fixes automatic positioning during Junon's first welcome parade in Steam 2026 x64 and stops repeated lost-track warnings from interrupting the remaining guidance.

## Changes

- The x64 parade assist sends directions through the game's native keyboard-state input, as normal autowalk already does. Previously it sent Windows key presses that the game did not register, then stopped because the requested direction was never acknowledged.
- Sustained parade movement renews its native input request on each valid frame. Ordinary autowalk releases its directions before the parade takes over, preventing the old route from cancelling the new movement.
- Once the assist stops after a fault, later unreadable snapshots no longer repeat the lost-track announcement. This correction applies to both runtime architectures.
- The player still presses OK in response to the existing timing sound or spoken cue. The assist controls directions only.

## Validation and coverage

Regression tests exercise the real x64 field coordinator with a simulated native keyboard overlay, covering sustained movement, handoff from ordinary autowalk, and release when gameplay cannot safely continue. Shared parade tests cover formation tracking, dialogue pauses, manual movement, OK timing, and the announce-once failure behavior. Ghidra inspection confirmed the legacy keyboard-state buffer and its native input consumer.

These are automated and native-data checks, not a completed in-game retest of the friend's parade attempt. Please report whether Cloud reaches the line and the timing cues can be followed after updating and restarting the game.

Live story playtesting has reached the first Gold Saucer visit and Corel Prison race. Later story guidance remains checked offline, not validated by a complete playthrough. Narration, description scripts, timing data and coverage are unchanged from 0.5.5. The complete replacement voice set has still not had an in-game audition.

## Downloads and updating

- **Blind-Soldier-Portable.zip:** both runtime architectures, including Steam 2026 x64.
- **Blind-Soldier-2013-x86-Portable.zip:** legacy 2013/7th Heaven x86 package.
- **ffviinew-v0.5.6-amm.zip** and **ffviiold-v0.5.6-amm.zip:** Accessibility Mod Manager packages.

Each archive has a SHA-256 sidecar. Follow the included README for the appropriate game layout. When updating a portable installation, preserve `Reloaded-II\Mods\ff7.accessibility.reloaded\Configuration\config.json` to keep your settings; the archive includes defaults. Restart the game to load the updated mod.
