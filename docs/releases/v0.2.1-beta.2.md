# Blind Soldier 0.2.1 Beta 2

This prerelease fixes opening-movie audio description for legacy x86 players
who run Echo-S through stock 7th Heaven and FFNx.

## What changed

- Keeps the existing physical movie file-handle detector as the primary signal.
- Uses FFVII's native field-movie playback state when FFNx serves Echo-S's
  opening video virtually and no ordinary movie file handle is visible.
- Rejects unreadable state and stale movie flags outside the field module.
- Does not modify Echo-S, 7th Heaven, FFNx, or any game movie file.

## Testing requested

With Echo-S enabled, start a new game through stock 7th Heaven, read and dismiss
the Echo-S introduction pages, and confirm that the recorded audio description
starts with the opening video and stops if the video is skipped.

## Installation

Two ZIPs are available:

- `Blind-Soldier-Portable.zip` is the complete dual-runtime package for Steam
  2026 x64 or installations that need both x86 and x64 support.
- `Blind-Soldier-2013-x86-Portable.zip` is the smaller package for direct 2013
  x86 or stock 7th Heaven/FFNx.

Close Final Fantasy VII and 7th Heaven, then extract the appropriate ZIP over
the existing Blind Soldier installation. Accessibility Mod Manager users can
install the matching beta update directly.
