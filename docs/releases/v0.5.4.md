# Blind Soldier 0.5.4

This prerelease adds controller navigation and expands recorded movie and cutscene descriptions. All narration recordings in these downloads use Brice's approved voice, including the opening. The previous narrator's recordings are not included in the new packages.

## Changes

- Recorded descriptions now include the opening and 99 other movie tracks, plus 618 short movie and cutscene action clips. Existing scripts and their attribution are preserved. Recorded narration is in English; ordinary game dialogue and screen-reader output keep their existing behavior.
- The opening uses the revised natural narration pace, clearer pauses and stronger narration volume from the title onward. Playback preparation and start synchronization have also been improved. The early star-field section still has a roughly 36-second gap between the existing description cues.
- Open the navigation menu with right-stick click (R3). Use D-pad Up/Down for targets, LB/L1 and RB/R1 for categories, A/Cross for spoken guidance, and X/Square for automatic walking. B/Circle or another R3 press while the menu is open stops navigation and closes it. R3 reopens the menu while a route is running.
- Controller selection has a delayed, paced D-pad repeat and separate bumper presses. Menu input is captured so it does not immediately close the menu or activate unrelated game actions.
- Steam 2026 x64 autowalk now supplies movement through the game's native input path, addressing attempts that failed to move the character and produced repeated unrelated screen-reader speech.

## Coverage and checks

Live story playtesting has reached the first Gold Saucer visit and Corel Prison race. Later story guidance remains checked offline, not validated by a complete playthrough. Description coverage is limited to the included scenes and action cues; optional events and remaining navigation trouble spots still need testing. Broader Steam 2026 controller and autowalk playtesting is welcome.

The four runtime test suites passed from the release source with the installed game data and existing test fixtures. Package and release-script checks passed, and Ghidra verified the packaged native bootstrappers and Version proxy. The standalone x64 test host does not exercise installation of the live keyboard hook; successful in-game autowalk was previously confirmed by the player. Narration audio hashes, scripts and timing data were checked against the approved export. The complete replacement voice set has not yet had an in-game audition.

## Downloads and updating

- **Blind-Soldier-Portable.zip:** both runtime architectures, including Steam 2026 x64.
- **Blind-Soldier-2013-x86-Portable.zip:** legacy 2013/7th Heaven x86 package.
- **ffviinew-v0.5.4-amm.zip** and **ffviiold-v0.5.4-amm.zip:** Accessibility Mod Manager packages; install them through the manager.

Each archive has a SHA-256 sidecar. Follow the included README for the appropriate game layout. When updating a portable installation, preserve `Reloaded-II\Mods\ff7.accessibility.reloaded\Configuration\config.json` to keep your settings; the archive includes defaults.
