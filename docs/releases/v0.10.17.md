# Blind Soldier 0.10.17 beta

- Start **Story** navigation once per room in Ancient Forest. It advances after the game returns control from pickups, throws, jumps, and tutorial messages. If you started **Auto Walk**, walking resumes on the next route. Use the usual controls to pick up, drop, throw, and jump.
- The entrance has two wider staging areas. Story recognizes insects dropped inside either area and guides you to the next insect. A visible insect that lands away from Cloud is announced with its direction when available.
- For this beta, try staging two insects, feeding the first plant, and letting Story guide you back to the next insect. The full timed crossing and the reported Run-button issue still need live testing.

This beta is available for Steam 2026 x64 and the 2013 x86 game, including 7th Heaven. Close the game before updating. If you use 7th Heaven, close it as well.
