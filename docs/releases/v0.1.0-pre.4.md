# Blind Swordsman 0.1.0-pre.4

This prerelease makes Final Fantasy VII the only software the player must
install before running Blind Swordsman setup.

- Setup now bundles and verifies Reloaded-II 1.30.3, Reloaded Shared Hooks
  1.16.3, and Microsoft .NET Desktop Runtime 9.0.8 for x86 and x64.
- A missing Reloaded-II installation is created automatically in a portable
  folder inside the selected game directory. A safe existing installation is
  repaired without replacing unrelated mods, profiles, preferences, or user
  configuration.
- The installer creates and merges the required Reloaded profile for the legacy
  x86 game as well as the existing native x64 profile.
- x86-only, x64-only, and dual-runtime game installations are supported
  independently; setup never requires the game version that is not installed.
- Uninstall removes only recorded Blind Swordsman files and profile changes.
  Reloaded-II, Shared Hooks, and .NET remain available as shared components.
- 7th Heaven and FFNx remain optional and are not installed or replaced.

Download `Blind-Swordsman-Setup.exe` for the standard screen-reader-accessible
installation. The installer is not code-signed yet, so Windows SmartScreen may
identify the publisher as unknown.
