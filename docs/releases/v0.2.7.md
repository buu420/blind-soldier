# Blind Soldier 0.2.7 (Beta)

This beta patch corrects the final Floor 63 coupon door, improves shared
manual and automatic route recovery, and restores highlighted dialogue-choice
tracking when FFNx voice support wraps the game's ASK handler.

## What changed

- Routes the Floor 63 coupon puzzle through the game's native D16 door after
  collecting the B Coupon, then exposes the C Coupon only after that door is
  open.
- Uses the matching native D16 state bit in both Story and Objects for the
  2013 x86 and Steam 2026 x64 runtimes.
- Keeps short obstacle-recovery waypoints active until Cloud actually moves
  through them, preventing automatic walking from discarding a detour while
  still stationary.
- Shares the corrected recovery behavior with manual navigation so both modes
  use the same connected route and collision evidence.
- Resolves the original ASK handler through FFNx's voice wrapper so choice
  dialogue can identify and speak the currently highlighted option again.

## Testing requested

On Floor 63, use the computer's `All Clear` option first if an earlier build
already opened the wrong third door. Follow Story through the A and B Coupons,
open the third door it selects, and confirm C Coupon becomes reachable. Test
automatic walking with `P` around walls or other obstacles and confirm it
continues through the recovery step instead of stopping or reversing.

With FFNx voice support active, open a dialogue choice and confirm the
highlighted option follows the cursor and can be selected normally.

## Installation

Two ZIPs are available:

- `Blind-Soldier-Portable.zip` is the complete dual-runtime package for Steam
  2026 x64 or installations that need both x86 and x64 support.
- `Blind-Soldier-2013-x86-Portable.zip` is the smaller package for direct 2013
  x86 or stock 7th Heaven/FFNx.

Close Final Fantasy VII and 7th Heaven, then extract the appropriate ZIP over
the existing Blind Soldier installation. Accessibility Mod Manager users can
install the matching beta-channel update directly.
