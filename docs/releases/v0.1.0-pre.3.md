# Blind Swordsman 0.1.0-pre.3

This prerelease fixes setup for players who have only one supported Final
Fantasy VII runtime installed.

- An x86-only installation now checks and deploys only x86 Reloaded loader and
  Shared Hooks files.
- An x64-only installation now checks and deploys only x64 files and does not
  construct legacy FFNx or opening-voice paths.
- A dual-runtime installation retains both backends and the existing
  accessible launcher integration.
- 7th Heaven and FFNx remain optional.

Download `Blind-Swordsman-Setup.exe` for the standard screen-reader-accessible
installation. The installer is not code-signed yet, so Windows SmartScreen may
identify the publisher as unknown.
