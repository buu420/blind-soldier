# Blind Soldier 0.9.8

The creature approaching at the end of Northern Crater now receives short
descriptions in the existing approved voice. The trigger observes its actual
native polygon draw, confirms movement has begun, and checks that owned opaque
triangles intersect the screen. A script request or visibility flag alone cannot
start a description.

Both approaches are covered in the stock field and all five reviewed Echo-S 1.24
field variants, in the 2013/7th Heaven and Steam 2026 runtimes. The later cue waits
for the game's warning to finish speaking. Paused or unreadable voice state is
not treated as completion. Controls, original dialogue and music are preserved.

The looping movie in this scene hides the static field background. Its room
description now waits for the native background layers to be presented, allowing
the observed creature cue to take priority. Creature recordings stop when their
presentation disappears, the mod is suspended, settings take ownership, or the
game loses focus.

Two new recordings are appended; all 1,512 earlier voice entries and recordings
are retained. The existing audio-description volume setting applies.

See [validation](../validation/crater-creature-20261012.md) for the native research
and regression evidence. These checks do not substitute for a live replay of
the final scene with a controller and screen reader.

Close the game before updating. Existing saves, settings and description history
are preserved.
