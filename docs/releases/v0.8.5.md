# Blind Soldier 0.8.5

This beta fixes submarine pursuit remaining in the overview when the target is
close enough for normal-view targeting. It applies to legacy x86/7th Heaven and
native Steam x64. Close the game before updating.

- Pursuit now uses the game's configured Target action to return to normal view
  automatically when approaching the selected contact. This includes the Huge
  Materia red leader. The action is released after a short press, and the mod
  waits for the game to confirm the view change. If it cannot confirm the change,
  pursuit stops and explains why.
- R3 opens targets, D-pad Up/Down selects, and A or X starts pursuit. Keyboard
  controls are J/L to select, O to toggle pursuit, I to start and K to repeat.
  Firing stays manual with the game's Switch control. The mod never forces a lock
  or fires a torpedo.
- View changes are spoken during manual play. An existing visible lock in the
  overview still gets firing guidance when a torpedo lamp is loaded.
- Guidance no longer tells players to press a literal Page Down key. The game's
  overview action follows its configured bindings; its legacy default is numpad
  3, which differs from the dedicated Page Down key.
- The submarine pursuit toggle moves from P to O because P is also Steam's
  default Pause key. Controller controls are unchanged.
- Temporary unreadable captures release input without repeating the same
  overview warning on every recovery. Pause, quit, focus loss, mission exit,
  manual steering and teardown retain their input-release behavior.

The change uses visible sightings or bounded fixed last-seen positions. It does
not track hidden live movement. Existing Gold Saucer fixes, narration, settings
and description history are preserved.

Native research and automated tests cover the view request, acknowledgement,
failed response, remapped bindings, lock guidance and native input overlay.
Actual controller hardware and live torpedo launches still require gameplay
feedback on both runtimes.
