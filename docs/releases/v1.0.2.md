# Blind Soldier 1.0.2

This update repairs the optional battery route during the climb to Shinra HQ and
keeps Aeris's upstairs bed findable with Echo-S.

- The optional battery socket is reachable using the native ladders and the game's
  automatic landing sequence. The planner now keeps the script's recorded landing
  instead of substituting a nearby ladder. Place the battery with the normal game control.
- Aeris's bed remains in Objects as visible scenery when its interaction is disabled,
  labelled **Bed (resting unavailable)**. When the game enables it, **Bed** uses the
  actual interaction region. Echo-S disables resting on later visits; this update
  preserves that behavior and the original first-visit sleep sequence.
- Navigation cues prepare and reuse their audio output. Approaching and leaving
  ladders clears or adds sound samples without opening or closing sound devices
  during the game update. Queued cues are bounded and audio failures stop further
  device access until the player is reinitialized.

The tester's accessibility log ended during ladder-cue playback setup but contained
no native crash stack. The route and audio lifecycle regressions are verified; the
reported crash still needs a live retest before its exact cause can be confirmed.

Both runtimes retain the 1.0.1 Echo-S dialogue controls, description reset options,
Honeybee narration, GOG identity support and the stock 7th Heaven/ReShade loader layout.
