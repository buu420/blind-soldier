# Blind Soldier 0.1.10

Blind Soldier 0.1.10 is a beta menu-accessibility update for both supported
Final Fantasy VII runtimes.

- Restores native Config row, value, and help-text speech in the legacy x86
  game.
- Makes the x86 Limit menu announce Set and Check correctly and removes the
  internal `[SWITCH]` control marker from spoken limit names.
- Makes the x86 Order menu announce each party member's front or back row,
  selected member, and swap state.
- Adds `R` as a foreground-only hotkey to repeat the last message Blind Soldier
  successfully spoke in either runtime.
- Keeps the Steam 2026 x64 and Steam 2013 x86 package layouts isolated.
- Does not modify Final Fantasy VII, 7th Heaven, FFNx, or the Windows registry.

The Steam 2026 x64 backend remains beta software. Reports should include the
newest file from `Blind-Soldier\Logs`.
