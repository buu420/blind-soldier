# Blind Soldier 0.5.5

This prerelease fixes controller navigation. The menu now follows whichever controller you click R3 on, stays open on the world map, and lets the bumpers change category there. Narration and recorded descriptions are unchanged from 0.5.4; these packages contain the same audio.

## Changes

- The navigation menu follows the controller you click R3 on. With more than one pad connected, the menu used to belong permanently to whichever controller the game happened to read first, so a PlayStation controller plugged in beside an Xbox controller could move the character normally but could never open the menu, with nothing reported. Either pad can now open it.
- A controller that does not have the menu keeps all of its buttons: it cannot take a menu somebody is already reading, and it has to wait until the press that closed the previous menu has been released.
- A controller that arrives with the right stick already clicked no longer counts that as a press, and a controller that is unplugged is forgotten rather than reopening the menu when it comes back.
- The world-map navigation menu stays open. It used to be closed silently a moment after it announced its first selection, because the field side of the mod asked the shared menu to close on every frame it was not the active one. LB/L1 and RB/R1 went to the game instead of changing category, which moved the camera.
- Selections queued on the world map are no longer discarded by that same closure.
- World-map navigation speech now takes priority over lower-priority world announcements, so a target readout is not talked over.
- The log now records each controller the game reads once, with its name and whether it has a right-stick click, and records when the menu changes hands. This is diagnostic information for controller reports.

## Coverage and checks

Live story playtesting has reached the first Gold Saucer visit and Corel Prison race. Later story guidance remains checked offline, not validated by a complete playthrough. Coverage of descriptions, optional events and remaining navigation trouble spots is unchanged from 0.5.4.

The controller ownership work was exercised against the installed SDL2 with two virtual controllers in an isolated host that really installs the capture hook, and the handoff, refusal and cleanup behaviour passed there. The standard x64 test host still cannot install that hook and reports so rather than passing quietly; that caveat is unchanged from 0.5.4. The world-map menu and shared-menu ownership fixes are covered by targeted tests reproducing the reported failures.

The specific controller and menu failure reported by a player has not yet been retested on their machine. Feedback from anyone using a PlayStation, Xbox or third-party controller is welcome, particularly on the world map.

Narration audio, scripts and timing data are carried over from 0.5.4 unchanged. The complete replacement voice set has still not had an in-game audition.

## Downloads and updating

- **Blind-Soldier-Portable.zip:** both runtime architectures, including Steam 2026 x64.
- **Blind-Soldier-2013-x86-Portable.zip:** legacy 2013/7th Heaven x86 package.
- **ffviinew-v0.5.5-amm.zip** and **ffviiold-v0.5.5-amm.zip:** Accessibility Mod Manager packages; install them through the manager.

Each archive has a SHA-256 sidecar. Follow the included README for the appropriate game layout. When updating a portable installation, preserve `Reloaded-II\Mods\ff7.accessibility.reloaded\Configuration\config.json` to keep your settings; the archive includes defaults.
