# Blind Soldier 0.8.4

This beta adds submarine selection, automatic pursuit and spoken firing guidance
to both legacy x86/7th Heaven and native Steam x64. Close the game before updating.

- **Select and pursue:** J/L cycle submarine sightings, P starts or stops automatic
  pursuit, I starts pursuit and K repeats status. Pursuit uses the normal steering
  and throttle controls; you fire manually with Switch.
- **Controller:** R3 opens the target list. D-pad Up/Down selects, A or X starts
  pursuit, and B or R3 from the open list stops. Opening the list releases steering
  while you browse.
- **Huge Materia submarine:** identifies the distinctive red leader hull separately
  from ordinary red arcade submarines. Every displayed contact can be selected.
- **Firing guidance:** says when the selected visible submarine is locked with
  torpedoes loaded, when they are reloading, and when the native lock is on another
  submarine. The game still chooses its own lock.
- **Contact memory:** only visible sightings update positions. A contact that
  disappears retains its fixed last-seen position for a bounded time, with speech
  identifying that loss of contact. In normal view, pursuit stops after reaching
  that old position without reacquiring the submarine. During the overview's
  blinking sweeps it can briefly hold course while waiting for the next sighting;
  an expired sighting always ends the pursuit.
- **Overview:** PageDown opens the overview for finding contacts. Return to normal
  view to lock and fire; the assist does not change your camera automatically.
- **Input release:** pause, quit prompt, unreadable state, focus loss, mission end
  and mod teardown release pursuit commands. Manual steering or throttle stops it.

The new tester log shows both recorded post-mission failure returns advancing
through Cloud's dialogue. That evidence does not establish the cause of the older
reported freeze; the read-only return trace remains available.

Native research and automated verification do not replace live gameplay testing.
Pursuit behavior, controller input and firing guidance still need gameplay
feedback on both builds. Existing narration, description history and settings are
preserved. The 0.8.3 Gold Saucer work is unchanged.
