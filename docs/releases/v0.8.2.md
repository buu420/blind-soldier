# Blind Soldier 0.8.2

This testing release adds speech to the late-game chocobo dismount menu on legacy/7th Heaven and Steam x64. Close the game before updating.

- Opening the menu reads its prompt and highlighted choice, including the option to send the chocobo back to the stables.
- Moving up or down reads the newly highlighted choice and its position. Waiting on an option does not repeat it, and reopening the menu reads it again.
- The reader uses the game's visible text and selection arrow. It waits for the arrow before announcing a choice, and leaves confirmation to the player.
- A shared reader error that suppressed valid world-map dialogue windows is corrected. Automatic walking remains paused while a dialogue or choice window owns movement.

## Testing

Automated checks cover the game's dismount text and native window layout, opening and closing the prompt, changing and reopening choices, ordinary world-map messages, and movement suspension on both runtimes. The x64 coordinator also has a direct choice-menu regression check. A live dismount test is still needed.

## Downloads and updating

- **Blind-Soldier-Portable.zip:** Steam x64 portable package, also containing the dual-runtime mod.
- **Blind-Soldier-2013-x86-Portable.zip:** legacy/7th Heaven portable package.
- **ffviinew-v0.8.2-amm.zip** and **ffviiold-v0.8.2-amm.zip:** Accessibility Mod Manager packages.

For a manual ZIP update, back up the entire `Reloaded-II\Mods\ff7.accessibility.reloaded\Configuration` folder, extract the matching ZIP over the game folder, then restore that folder. This preserves settings and description history. Existing recordings and saves are unchanged.
