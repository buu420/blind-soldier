# Blind Soldier 0.1.8

Blind Soldier 0.1.8 is a beta gameplay-accessibility update for both supported
Final Fantasy VII runtimes.

- Restores state-aware Story navigation through the first Wall Market visit.
- Adds battle-only hotkeys for selecting a party member and checking HP, MP,
  buffs, debuffs, and the live limit-gauge percentage.
- Keeps the overlapping `L` key assigned to navigation outside battle.
- Corrects native Enemy Skill and Summon selection mapping so names, MP costs,
  and descriptions match the visible battle menu.
- Restores nested Save-slot and confirmation speech.
- Restores Save speech when the stock Save overlay is opened from the world
  map.

The Steam 2026 x64 backend remains beta software. Reports should include the
newest file from `Blind-Soldier\Logs`.
