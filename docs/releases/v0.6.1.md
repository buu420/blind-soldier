# Blind Soldier 0.6.1

This prerelease repairs observatory navigation in Cosmo Canyon for both legacy x86/7th Heaven and Steam 2026 x64, and adds eight action descriptions in Brice's voice.

- Navigation now approaches the observatory's door-opening triggers on the way in and out, retains the selected destination while the door opens, and resumes requested auto walk afterward.
- Fixed the upstairs corner where auto walk could stop short of the exit. Spoken guidance also keeps giving directions near the door.
- Added **Talk to Red XIII** to Story for the first observatory visit, so the planet-display event can be started through Story navigation.
- Added eight short action descriptions at the Cosmo Canyon bonfire, Shinra Mansion, Rocket Town, and Temple of the Ancients. The short-recording total is now **846**. Existing recordings and movie narration are preserved.

The fixes passed automated route and story checks using both installed game archives, plus the full x86 and x64 test suites. Live play-testing of the repaired observatory route is still needed. This release does not claim complete cutscene coverage and adds no new FMV narration.

## Downloads

- **Blind-Soldier-Portable.zip:** both supported game runtimes.
- **Blind-Soldier-2013-x86-Portable.zip:** legacy 2013/7th Heaven x86.
- **ffviinew-v0.6.1-amm.zip** and **ffviiold-v0.6.1-amm.zip:** Accessibility Mod Manager packages.

Each archive has a SHA-256 sidecar. Preserve `Reloaded-II\Mods\ff7.accessibility.reloaded\Configuration\config.json` when updating a portable installation. Restart the game after updating.
