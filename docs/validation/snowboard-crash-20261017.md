# Snowboarding startup crash: native x86 ABI

The report says starting snowboarding crashes with Echo-S enabled or disabled. Legacy x86 is suspected. No fresh crash log or dump accompanies this report; the newest Downloads log is the previously reviewed October 15 file. Historical Steam x64 logs contain successful course cues from September 28, which is earlier-version evidence rather than a current live test.

Ghidra 12.1.2 analysis of the supported `ff7_en.exe` identifies `0072F9F4` as the snowboard ASCII font renderer. It saves ECX at `0072F9FD` and returns with `RET 14h` at `0072FDFC`. Its caller `0072D333` loads the owner into ECX, pushes five arguments and calls it at `0072D360`, without caller cleanup. These instructions establish Microsoft thiscall independently of inferred decompiler types. Pseudocode is not recovered engine source.

The legacy `MenuTextRendererDelegate` and detour previously used Cdecl and omitted the owner. A native x86 caller driven through the production callback reproduced an ESP delta of -20 where the caller requires zero. The correction supplies the owner in ECX, forwards it to Original, and declares MicrosoftThiscall/ThisCall consistently. The translated x64 callback uses its existing physical host ABI and guest-register handling.

`SnowboardTextHookAbiTests` checks native stack balance and 32 calls through the production callback to an instrumented native Original, asserting the ECX owner, all five arguments and exactly one Original call. With licensed installed game data, it verifies the executable hash and font instructions, runs the unhooked function, then invokes the actual copied native font body through the production callback 128 times. Native context zero takes the renderer's existing no-draw branch, so this requires no game-state writes or graphics initialization. Licensed code is read locally and is not committed or packaged.

Only the external Reloaded-II controller's Original property is substituted in the standalone test. The production callback, native callers and native Original bodies execute. The test does not launch Reloaded-II or exercise its live installed trampoline. An initial attempt to instantiate the standalone NuGet hook factory hit its existing Reloaded.Assembler/Reloaded.Memory type-loading mismatch; that test-harness failure is retained privately and is not claimed as the snowboarding root cause. Product dependencies are unchanged.

The hook installation and native font ABI do not depend on Echo-S field scripts or voice playback. The same correction applies with either Echo-S state. Player profile toggles are preserved. Existing snowboard tests retain the seven story segments, 601 positions, three forks and four endings, and restrict announcements to rendered geometry.

Review found a separate issue in the newly reachable raw-font speech path. The Gold Saucer menu renderer (0072D6C8) uses the selected row's pulsing colour supplied by 0072E5EC, while both generic speech keys include that colour and the configured settle time is zero. A production-callback replay reproduced 24 generic announcements across three selections' 16-frame pulse sequences and a partial result. The hook now retains diagnostics and Original calls without feeding this font into generic menu speech. The regression checks all selections, telemetry, one native Original call per draw and no swallowed callback errors. Existing course cues and other menu-text feeders remain intact. Dedicated Gold Saucer snowboard menu, score and record narration is not added by this crash repair and remains a documented gap.

Independent review checked the installed shared hook controller (Reloaded.Hooks 4.3.2, Definitions 1.15.0). Its MicrosoftThiscall/ThisCall pairing uses the same CLR marshalling exercised by the test; the untested live host boundary includes the jump and relocated nine-byte prologue. No installed trampoline execution is claimed.

Run the focused legacy regression with `--snowboard-crash-only`. The existing `--glacier-speech-only` group covers the shared course/readout behavior in both hosts. The new native ABI regression also runs in the default legacy suite. Full release and exact-package verification records are retained with the release evidence.

A live current-version snowboard run with Echo-S on and off, physical controller/keyboard interactions and audible Prism output remain untested. Automated native ABI execution is not a live gameplay test.
