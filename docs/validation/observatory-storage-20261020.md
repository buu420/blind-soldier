# Huge Materia observatory navigation, 20 October 2026

The tester's 0.10.2 Steam x64 log records field 542 (`bugin1b`) at game moment 1391. Objects is empty and three storage stands appear as Story objectives. Seven auto-walk stalls target `gateway:542:0:544`, ending at coordinates with z=-1792. The doorway left in this field's data lies at (-378,30,-36), copied from the ordinary observatory. Projecting that gateway onto the display floor produces a route that cannot perform the return.

The installed scripts establish the actual interaction. Each of entities 11–14 has a Contact script, without Talk. Its ASK contains Get closer, Leave it alone and Go back down. Returning requests AD entity 9's script 3, whose MAPJUMP returns to field 541, or Bugenhagen's story departure through entity 10's script 4. The tester log also observes the three-choice window. Echo-S moves these choices from lines 1–3 to 0–2; navigation never writes a choice or assumes an answer index.

Contact semantics follow the existing Ghidra findings for 00636C41/00637724: the movement probes, model collision widths and strict height band determine touch; observing the native Contact script start completes the approach. The existing ASK handler and [documented opcode operands](https://wiki.ffrtt.ru/index.php/FF7/Field/Script/Opcodes/48_ASK) distinguish the displayed choice from its stored answer. Raw licensed scripts and native exports remain private.

The fix adds Contact support to the shared Objects reader and four slot-gated named Materia objects. Visibility and collision must be enabled. Their native positions and widths are read live. Each stand is named by its visible colour: 11 yellow, 12 green, 13 red and 14 blue. This is bound through CHAR 9–12 and the actual HRC/RSD/P model chain, whose untextured vertex/polygon colours corroborate the loader names. Both installed data archives and five Echo-S layouts retain those bindings. No mission or hidden reward is inferred, and no visit history hides a repeatable stand. Other model replacements have not been evaluated. The old four Story rows and their generator definitions are removed.

Exit aliases reuse those same slot gates and Contact ranges through the existing shared exit-reader seam. Each names its stand and explicitly says to choose Go back down. The obsolete gateway is suppressed only in field 542; field 541 retains its normal doorway. Contact completion stops auto walk when the menu begins. The player selects and confirms the native return option; no input, transfer, flag or physics is written by this repair.

The required initial departure remains in Story as one Go back down objective, under moment 1391 and bank 3[188] bit 3 clear. Available stand approaches have distinct priorities so only one objective is offered. The native AD script 4 sets that bit and transfers the party to the Highwind; the objective disappears afterward. Optional repeat examinations remain in Objects. This corrects an omission found by independent review before release.

Independent review also found that Steam's spatial-sound reader rejected named objects with the default NativeId=-1, even when they had an explicit cue override. It now accepts named model cues with a nonempty label and an explicit Item, Materia or Chest cue, without treating them as pickups or resolving a hidden reward. Its two checked reads, visibility gates and other validation remain in place. A regression first fails on the old rejection, then verifies four named Materia sound targets and removal of a hidden stand.

Focused regressions first failed because no stored Materia appeared in Objects and no native menu exit was offered. The repaired readers and controller check all four slot gates, hidden and non-collidable models, later/repeat visits, native reach and height limits, both Objects and Exits contact arrival, and suppression of only the obsolete gateway. Installed walkmesh checks cover all four stand placements from all seven reported stalled positions: 28 approaches per runtime. Native choice and return-script checks cover both installed game archives and five available Echo-S overlays. Both full runtime suites include the regression.

These are automated/native-data checks, not a live playthrough. Real-time traversal, physical controls and audible Prism feedback for this repair remain unverified.
