# Ancient Forest puzzle accessibility

The user approved this scope for Blind Soldier 0.10.9: distinguish the visible insects,
frogs, plants and crossings; report the carried creature and visible plant changes;
guide usable hopping and vine routes to items and exits. Creature placement, puzzle
choices, button-triggered jumps and reset remain normal game actions. Support the
2013 x86 and Steam 2026 x64 runtimes and the five reviewed Echo-S layouts, deploy,
and publish to the established GitHub and Mod Manager channels.

The supplied 0.10.8 log reaches entry field 622 (anfrst_3). Existing Objects already
include creatures, throwing spots and some gated takeoffs, but duplicate creature
names and absent carrying/plant feedback make the puzzle difficult to follow.
Existing native route guards must remain intact. Native scripts and collision
geometry, corroborated by Ghidra's LINE-crossing and JUMP handlers, determine usable
routes; a walkthrough is not a source of runtime state.

Use stable local numbers to distinguish visually separate creatures and plants.
Read coherent native temporary-bank state only for reviewed loaded scripts. Speak
the current carrying/plant state through the existing activity/repeat delivery,
without a backlog of expired timed-plant readings. Unknown samples stay unknown.
Only usable crossings are offered, with the required native direction or button.
Include visible vines and reset guidance where the native field presents them.
Keep rewards under their native visibility and collection guards. No hidden solution,
future timer, hidden contents, changed timers or automatic puzzle actions.

Retain the sole source checkout in Dropbox. Preserve saves, settings, recordings,
native binaries and unrelated mods. Automated/native-data and package checks are
separate from live gameplay, controller and audible listening proof.
