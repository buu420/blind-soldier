# Story and entity verification

The reported failure is an empty Story category in the present-day Nibelheim
mansion after Cosmo Canyon. The investigation also found that
`MainStoryCoverageTests` is not included in the x64 test project. A definition
count or a successful build cannot establish a playable route.

1. Reproduce the present-day mansion states against the released catalog. Review
   the native triggers, return paths, NPCs and optional interactions in both
   installed field archives. Claude owns the Nibelheim repairs and focused tests.
2. Add a reusable audit executable, compiled against either actual runtime. It
   inventories the native fields and checks authored entities, triangle bounds,
   enabled-line references and independently specified playable checkpoints. It
   reports unreviewed native interactions separately from failures; absence from
   a static inventory is not proof that an interaction must be a Story objective.
3. Run the broad existing story regressions on x64 too. Add explicit regression
   coverage for the post-Cosmo state and optional-room return paths. Require a
   missing checkpoint to fail, including when the entire region is absent.
4. Run the audit on both installed archives and both runtime assemblies, review
   differences and actionable gaps, then run the affected and full suites. Deploy
   both local builds, preserving configuration and recorded narration.

No version bump or publication is part of this request. Native script identity,
conditional state, visible actors and actual entrances govern targets. Optional
content must not become a mandatory story detour. Static discovery, state replay,
walkmesh replay and live play are distinct evidence levels and must be reported
as such. Minigame mechanics are outside this pass.
